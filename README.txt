Projet : Quiz de compréhension orale
====================================

Page élève
----------
Ouvrez index.html pour tester le quiz.
Le français est utilisé pour tous les titres et les consignes.

Ordre de chaque question :
1. Audio
2. Question
3. Choix de réponses

Questions 7 à 10
----------------
Les fichiers audio actuels sont des copies provisoires.
Vous pouvez les remplacer plus tard par les vrais fichiers :
audio_7.mp3, audio_8.mp3, audio_9.mp3, audio_10.mp3.

Modification des questions
--------------------------
Dans questions.js :
- audio : nom du fichier audio
- question : question affichée
- options : les 4 choix
- answer : numéro de la bonne réponse (0 à 3)
- sentence : phrase française correcte affichée après le résultat

Remarque
--------
Cette version de test est autonome pour éviter l'erreur de la page précédente.
Le réglage PLAY_LIMIT dans index.html est provisoire. Il sera ensuite contrôlé
depuis le tableau de bord.
